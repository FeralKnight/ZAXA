# ZAXA

Web de ropa deportiva en rojo, negro y blanco.

## Desarrollo

`npm install` y `npm run dev`. Publicación: importar FeralKnight/ZAXA en Vercel con framework Next.js.

## Configuración

Configurar las variables de `.env.example` en Vercel. El catálogo utiliza almacenamiento persistente privado; ninguna credencial se incluye en GitHub. Las cuentas se verifican en el servidor y las sesiones usan cookies HttpOnly.

## Funciones

- 24 prendas de presentación en Faldas, Tops, Joggers y Shorts.
- Novedades por 14 días desde su publicación.
- Ofertas programadas o indefinidas; porcentaje o importe por unidad.
- Panel con catálogo, colecciones, ofertas e historial.
- Acceso individual de Oscar, Ale y editor.

Las imágenes son conceptuales y los precios de muestra. Los datos definitivos se cargan desde el panel.
